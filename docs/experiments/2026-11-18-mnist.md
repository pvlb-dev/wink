# 2026-11-18 — first MNIST diffusion runs (CPU, t14)

First end-to-end WINK run. All numbers are CPU, one seed (1337), 28×28 MNIST,
4×4 patches (49 tokens), batch 64. No FID; MNIST is a smoke test.

## What was built

- `wink` package: patchify, MNIST/CIFAR loaders, Gaussian diffusion, time rotor,
  hyper and RAT denoisers, trainer, MLflow logging, `wtrain`/`wsample`.
- 26 tests green; CI workflow ready.
- Private `agentic/wink` knowledge repo; Forgejo milestone M1 and issues #2–#9.

## What the failures taught

1. **1,000-step epsilon at 0.24M is a bad sampler regime.** At 3k steps the
   model denoised t=100 well (x0 MSE 0.04) but its high-t x0 estimate was
   amplified by ~160× (`1/sqrt(alpha_bar)`) and the DDIM chain stayed noise.
2. **More steps alone did not fix it.** 10k epsilon lowered val loss to 0.095
   but samples were still noise; the loss is dominated by low-t epsilon error,
   which matters less for sampling.
3. **x0 prediction + 200 steps is the practical fix at this budget.** The target
   is bounded and the sampler no longer amplifies a high-t error. Digits appear.
4. **Capacity helps but is not the whole story.** 96×6 hyper (0.79M) beat the
   0.24M hyper, but RAT-16 (0.24M) beat both at 3k steps.
5. **RAT loves many heads here.** RAT-4 was 1,033 ms/step; RAT-16 was 398 ms/step
   (2.6× faster) and had the best loss/sample quality. The operator's text-domain
   observation transferred to 49-token images.

## Best recipe

`examples/configs/mnist_rat.yaml`:

```yaml
model: {arch: rat, level: 1, image_size: 28, patch_size: 4,
        n_head: 16, n_embd: 64, n_layer: 4, time_conditioning: rotor}
diffusion: {timesteps: 200, prediction: x0, sampler: ddim, sampler_steps: 50}
trainer: {batch_size: 64, max_iters: 3000, learning_rate: 1e-3,
          ema_decay: 0.999}
```

Reproduce:

```bash
uv sync --locked --extra mlflow
.venv/bin/wtrain -c examples/configs/mnist_rat.yaml
.venv/bin/wsample -c examples/configs/mnist_rat.yaml \
  --checkpoint examples/saved/mnist_rat_h16/final.pt \
  -n 64 --steps 50 -o rat.png
```
