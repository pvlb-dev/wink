# Archived experiment configs

These are the configs behind the historical notes in `docs/experiments/`. The
public `examples/configs/` folder intentionally contains only the two entry
points needed for v0.1:

- `examples/configs/mnist_rat.yaml` — simple M1 RAT-16 run.
- `examples/configs/mnist_rat_cond_cfg_h32_10k.yaml` — the 10k promptable model
  used by the browser demo.

The full pre-0.1 examples tree (including checkpoints and cached data) is kept
in the private `AGENTS.d/examples/` archive. These copies are here so the
historical reports stay reproducible without cluttering the quickstart.
